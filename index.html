CRYPTOGRAPHY LAB

Cipher Techniques

Study classical cryptographic techniques and experiment with their basic concepts.

01 SUBSTITUTION

Caesar Cipher

A substitution cipher that shifts each letter by a fixed number of positions.

HELLO → KHOOR
02 MATRIX

Hill Cipher

A polygraphic substitution cipher based on matrix multiplication.

MATRIX × KEY
03 DIGRAPH

Playfair Cipher

Encrypts pairs of letters using a 5×5 key matrix.

MEET → KEY
04 SUBSTITUTION

Monoalphabetic

Each plaintext letter is consistently mapped to another ciphertext letter.

A → Q • B → W
05 POLYALPHABETIC

Vigenère Cipher

Uses a keyword to perform multiple Caesar-style shifts across the message.

TEXT + KEY
06 THEORETICAL

One-Time Pad

Uses a truly random key that is as long as the plaintext.

TEXT ⊕ KEY
